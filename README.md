# Ruby_day02

### 📄 Code Explanation

This Ruby program is a student grading system.

- It starts by asking the user how many students data they want to enter.
- It then loops through each student using a `while` loop.
- For each student, it takes the name and marks as input.
- The program uses `if-elsif-else` conditionals to assign a grade based on the marks:
  - Grades range from A1 to E2 based on the marks.
- It also correctly handles suffixes like `1st`, `2nd`, `3rd`, `4th`, etc., using conditionals and a `case` statement.
- At the end result is displayed.

### ✅ Concepts Used:
- Input/output using `gets.chomp`
- Data conversion using `.to_i`
- Loops (`while`)
- Conditional logic (`if`, `elsif`, `else`)
- `case` statement for suffix handling
- String interpolation (`#{}`)
